# По следам слов

Сайт проекта «По следам слов»: цифровое путешествие по эвенскому языку.
Кейс-чемпионат «Цифровое единство: языки народов России», РУДН, команда «РКИШНИКИ».

Чистый фронтенд: HTML + CSS + JS, без бэкенда и сборки.

## Адрес сайта

https://ounme.github.io/po-sledam-slov/

## Структура

- `index.html` — вся страница (одна, с якорной навигацией)
- `css/style.css` — стили
- `js/main.js` — данные маршрута и вся интерактивность (карта, конструктор слова, карточки)

## Локальный просмотр

Из папки `site` выполнить:

```
python -m http.server 8000
```

и открыть http://localhost:8000

## Как обновить сайт

Сайт публикуется из ветки `gh-pages` репозитория `ounme/po-sledam-slov`.

```
git add -A
git commit -m "Описание изменений"
git push origin gh-pages
git checkout main && git merge gh-pages && git push origin main && git checkout gh-pages
```

После пуша изменения появляются на сайте в течение 1-2 минут.

## Альтернативные бесплатные хостинги (доступны из России)

Если GitHub Pages будет недоступен или потребуется другой адрес:

1. **Netlify Drop** (проще всего): зайти на app.netlify.com/drop и перетащить папку `site` в окно браузера. Нужна учётная запись Netlify, регистрация по email. Сайту сразу дадут адрес вида `name.netlify.app`.
2. **Cloudflare Pages**: хорошая скорость из РФ, бесплатный тариф с безлимитным трафиком. Публикация через git-репозиторий или загрузку папки через Wrangler.
3. **Codeberg Pages** (codeberg.org): европейский аналог GitHub, для статики бесплатно, работает из РФ.
4. **Российские конструкторы** Tilda или uCoz: вариант, если нужно править сайт без кода, но дизайн придётся собирать заново внутри конструктора.

Свой домен (например `.ru`) можно подключить к любому из этих вариантов, бесплатный SSL прилагается.
